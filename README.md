# RimSort

### Fast, modern mod sorter for RimWorld

RimSort is a standalone mod manager and load order tool for RimWorld. With automatic sorting via community rules, conflict detection, and a clean interface, it's the fastest way to keep your RimWorld mod setup healthy.

<br>

---

## Features

| | |
|:---|:---|
| **Auto-Sort** | Applies community-sourced sorting rules for maximum compatibility |
| **SteamDB Integration** | Checks mod versions against Steam Workshop for update detection |
| **Conflict Reports** | Detailed reports of known incompatibilities between your mods |
| **Fast Performance** | Handles mod lists of 1000+ mods without slowing down |
